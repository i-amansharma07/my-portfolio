## About

Blood Sweat Cheers revolutionizes fitness by focusing on **quality over quantity**. This isn't just another workout app - it's your personal trainer that emphasizes correct form, proper breathing, and technique over heavy weights.

> _"Training your body should not be a thing from which you run away and have a load of boredom. Working out isn't just about lifting heavy weights - it's about how well you do every rep."_

## 🛠️ Technology Stack

### 📱 Frontend

- **Kotlin** - Modern, expressive programming language for Android development
- **Android Framework** - Native Android SDK for optimal performance and user experience
- **Material Design Components** - Following Google's design guidelines for consistent UX

### ⚡ Backend Services

- **Node.js** - Server-side runtime powering the quotes delivery system
- **Express.js** - Web framework for building RESTful APIs
- **Firebase Firestore** - NoSQL database storing user data, workouts, and app content
- **Firebase Authentication** - Secure user authentication and account management
- **Firebase Storage** - Cloud storage for workout videos and images

### 🏗️ Architecture

```
📱 Android App (Kotlin)
    ├── 🎨 UI Layer (Activities, Fragments)
    ├── 🔄 Data Layer (Repository Pattern)
    └── 🌐 Network Layer (Retrofit)
                    ↓
☁️ Firebase Backend
    ├── 🔐 Authentication
    ├── 📄 Firestore Database
    └── 📁 Cloud Storage
                    ↓
🚀 Node.js API Server
    ├── 💬 Daily Quotes Service

```
